# UI fonts

`InterVariable.ttf` is the open-source Inter font by The Inter Project
Authors, licensed under the SIL Open Font License 1.1 (see `Inter-OFL.txt`).

The runtime uses pre-rendered, anti-aliased bitmap atlases generated from this
font by `tools/fontgen` (work in progress). The original TTF is kept here for
reproducible asset generation; it is not embedded in the kernel.

Source: https://github.com/google/fonts/tree/main/ofl/inter
