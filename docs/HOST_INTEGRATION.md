# 宿主显示适配与显式粘贴（0.8）

## 启动前确定，运行后锁定

`make run`在启动QEMU前读取宿主屏幕像素尺寸，并把选定模式同时写入Limine配置和QEMU VGA EDID。macOS优先使用NSScreen尺寸探针、其次CoreGraphics；Linux使用xrandr。尺寸探测失败时明确回退1440×900，可通过 `make run RESOLUTION=2880x1800` 指定。

**运行后不再监听QEMU窗口几何，不会自行反复修改分辨率。** 旧监听实现会把“客体模式改变导致的QEMU窗口大小变化”误认为用户调整，造成每次减去标题栏高度、循环缩小再跳回的反馈；已从启动器删除，不只是加延时掩盖。

宿主窗口缩放或全屏使用QEMU zoom-to-fit显示同一个客体模式。需要改变真实客体模式时，显式运行一次 `make resize RESOLUTION=1920x1080`。该操作使用私有COM2尺寸通道，经范围检查和CAP_FRAMEBUFFER授权配置Standard VGA；没有后台重复发送。窗口模式使用 `RUN_FULLSCREEN=off`。

支持1024×700至3840×2160，宽度8像素对齐；宽≥2560且高≥1400时采用2×UI。超大屏幕在启动时按比例限制到渲染器上限，这种情况仍可能出现宿主缩放，不能声称全尺寸原生适配。当前仅验证QEMU Standard VGA（1234:1111），未验证任意真机GPU。

字形使用对应物理字号图集，SVG与圆角按物理像素绘制，不把低分辨率整幅画面放大冒充HiDPI。手动切换模式时保留用户身份、模型与登录输入，窗口重新布局。`graphics_smoke.py`验证了多种运行中模式的实际截图尺寸；宿主无显示的工具环境无法验证真实Cocoa全屏外观，启动失败/回退会明确报告。

## 粘贴密码

1. 在宿主复制**密码本身**，不包含用户名、冒号或换行。
2. 点击客体登录框中的密码输入框。
3. 在项目终端运行 `make paste`。
4. 切回客体，手动按Enter登录。

也可向 `python3 tools/paste.py --stdin` 管道输入文本（不要加换行）；不要把密码放进命令参数或shell历史。脚本默认读取系统剪贴板：macOS pbpaste、Wayland wl-paste、X11 xclip。不后台轮询，不自动同步剪贴板，不读取`.local/initial-passwords.txt`。

该路径是开发期显式“输入文本”操作，通过QMP发送US键盘按键。它不是客体系统剪贴板协议，也不是QEMU窗口内Cmd+V；不自动按Enter。当前仅支持1–63个可打印ASCII字符，遇到换行、Tab、控制字符、非ASCII或过长内容时整次拒绝。使用时释放Shift/Ctrl/Alt并关闭客体CapsLock。目标输入框自身的长度限制仍然适用。

启动器为每次运行创建0700临时目录，QMP/resize套接字和状态文件使用0600权限。相同输出目录只能运行一个启动器；退出清理端点。QMP具备完整虚拟机控制能力，所以不开放TCP或共享权限。粘贴脚本不打印文本/按键payload，不在串口或文件中记录；Python进程中的字符串不能保证即时内存擦除，不应将其描述为安全密码通道。
