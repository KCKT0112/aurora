# 当前任务清单与优先级

更新：2026-10-29。原则：先补底层契约和可验证的行为，再扩展应用数量；借鉴Unix/Linux语义，保留微内核方向。

| 优先级 | 任务 | 本轮结果/完成标准 |
|---|---|---|
| P0 | 启动分辨率稳定 | 已做：启动前检测并写入引导配置；启动后锁定，删除自动窗口尺寸监听，避免客体→宿主→客体反馈循环；可显式make resize |
| P0 | WAV播放所需文件和PCM链路 | 已做：owner绑定只读句柄、pread/close/显式委托、64KiB一次性复制授权；用户态WAV解析/转换；AC97 PCM输出；完整用户WAV2874403帧、零underrun、输出频谱和权限回归通过 |
| P0 | 音频/文件权限与资源安全 | 已做：普通应用不能操作DMA，数据复制到内核固定DMA页；句柄/授权不能猜测跨进程使用；退出/注销/权限降低停止读取；有界配额 |
| P1 | 持久化块设备与VFS | 下一项：用户态块服务、持久化格式、挂载、fsync/断电一致性；现有RAM修改仍不持久 |
| P1 | 完整文件描述符接口 | 继续：顺序read/write、seek、进程退出统一回收、打开文件与unlink语义；当前只读句柄是明确受限的阶段实现 |
| P1 | 可恢复服务与exec/wait | 进程退出状态、父子关系、凭据/fd继承、核心服务监督；避免把崩溃后盲重启当恢复 |
| P1 | 图形surface与帧节奏 | 按需分配窗口backing store、damage列表、硬件page flip/vsync，量化帧时间而不是仅凭静态截图 |
| P2 | 驱动用户态化 | 受限MMIO/IRQ/DMA句柄、IOMMU/撤销；迁出当前内核AC97/virtio硬件机制，完成微内核边界 |
| P2 | 账号与安装模型 | 服务专用UID、附加组、持久化账号配置、签名包与受限动态加载 |
| P2 | 扩展音频 | PCM共享流、混音/音量、更多声卡；浮点WAV/多声道/压缩格式在规范与测试完备后增加 |
| P3 | 内核升级与兼容 | A/B引导、回滚与稳定ABI；完整热切换单独研究，不能冒充已完成 |

本轮最高优先级是 **启动稳定 + 能实际播放用户WAV的受限I/O与PCM链路**。用户文件保持原始24位48k双声道内容；播放时转换到设备的16位48k双声道。没有为了演示偷偷转码源文件，也没有声称已完成持久化、完整POSIX或通用真机音频驱动。
