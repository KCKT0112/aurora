# Aurora 工作区设计规范

桌面以实际任务为中心：Files 默认打开用户目录，Monitor 提供运行状况，Terminal 执行基础命令，Settings 说明会话和音频。删除旧版 Welcome/Session 演示窗口，不把 ring 3、syscall 等实现术语堆在主界面。

视觉采用浅色纸面、灰绿桌面、低饱和绿色强调、Inter 字体，终端使用深色阅读区。统一 44px 标题栏、12px 圆角、32px 表格行、24px 文本行；焦点以边框和应用栏选中态表达。图标源位于assets/icons，为24×24 SVG；构建时将M/L/C/Z与circle编译为定点矢量线段，运行时4×4覆盖采样抗锯齿并缓存。阴影使用圆角距离场与连续衰减，只混合边缘区域。UI 当前使用英文；中文字体、输入法和完整 UTF-8 文本排版尚未支持。

Files 左侧为 Places，主区域有上级按钮、路径、刷新、名称与信息列；选中与激活分开，双击或 Enter 激活。空目录、未加载状态和只读/RAM 会话必须明示。Preview 为独立文档视图，支持按行滚动。Terminal 有有界历史、命令编辑和服务响应，阻塞 RPC 期间保留有界 typeahead。

窗口右侧依次为最小化、最大化/还原、关闭视图。关闭不终止进程；后台模型更新不能重新弹出被隐藏的窗口。应用栏恢复视图。F1 切换可见窗口，F2/F3/F4 打开 Terminal/Files/Monitor，F5 刷新文件列表。应用终止操作在 Monitor 明确提示，两次 Delete 确认并保护系统服务。

合成路径：缓存壁纸 → 私有 canvas 按 damage 范围绘制 → 单次区域提交 → 离屏光标。指针移动不重绘整个桌面；事务只在完整模型到达后提交。当前仍使用单个合并 damage rectangle，多个远离窗口更新可能扩大重绘面积。没有 vsync、GPU 加速或任意尺寸 app surface，不承诺30/60fps。

参考布局1440×900；接受1024×700到3840×2160，并支持2×逻辑UI，越界模式拒绝。较小分辨率窗口会重叠，标题栏与应用栏仍可操作。已支持四边/四角拖动缩放，带方向光标、最小尺寸、工作区约束与内容裁剪；主题切换、辅助功能和本地化属于后续工作。

## 登录与显示适配

未认证只显示登录界面，默认username=user；Tab切换字段，Enter提交，密码遮蔽。Settings或Terminal logout注销，旧窗口模型清空。显示当前账号名称，root终端提示符为#，普通用户为$。Files侧栏基于当前home生成。

`make run`启动前检测宿主像素并配置一次，启动后锁定；不再跟随QEMU窗口几何，防止尺寸反馈循环。手动make resize可重新配置Standard VGA与离屏画布；2×字体/图标/圆角原生绘制，不拉伸整张1×画面。采集不可用时由QEMU缩放回退。见 [宿主集成](HOST_INTEGRATION.md)。

## 光标和输入提交

旧路径在绘制场景前恢复可见framebuffer的save-under区域，导致光标在合成期间消失。现在pointer事件只更新位置/dirty状态；canvas始终保存不含光标的场景，提交前在canvas临时合成光标，提交damage及新旧光标区域后，仅在canvas恢复背景。可见framebuffer不会出现“先清掉光标，再花时间合成”的空档。

tablet可用后input不再发送PS/2相对移动；virtio按SYN_REPORT保留按钮边沿，同源同按钮状态的相邻motion才可合并。新鲜位置优先，按键和点击顺序不改变。整数坐标归一化采用就近舍入；未变化的模型不重复触发重绘。

软件提交仍不是硬件page flip/vsync，模式切换和跨区域写入可能有短暂撕裂；未承诺恒定60fps。高分辨率当前预留两张UHD画布，display私有映射约67MiB；后续需要按需surface分配和更多区域级优化。
